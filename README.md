# Train Ticket Booking System – Java Project

This is a simple **Java Train Ticket Booking System** designed for beginners. The program allows the user to enter their personal information first and then choose a train route from a list of available destinations.

### Main Features

* **Passenger Information:** At the beginning, the user enters their name, surname, and other basic information.
* **Train Destinations:** The program displays **4 cities in Albania** as available destinations.
* **Departure Time:** Each city has a specific train departure time.
* **Ticket Price:** Each destination has a different ticket price.
* **City Selection:** The user chooses the city they want to travel to.
* **Ticket Summary:** At the end, the program displays the passenger's information, selected city, departure time, and ticket price.

### Technologies

* Java
* `Scanner` for user input
* Variables and data types
* `if/else`
* `switch`
* Arrays
* Basic methods

### Project Goal

The purpose of this project is to create a simple **train ticket reservation system** while practicing fundamental Java programming concepts. The project is suitable for beginners and focuses on user input, menus, conditional statements, and displaying information.

At the end of the process, the user receives a simple ticket containing their **personal information, destination, departure time, and ticket price**.
